# 🏦 Bankcore — Modern Banking Database

> A clean, secure & scalable SQL database design for a modern banking system.

### ✨ Why Bankcore?
Bankcore solves disorganized banking data. It provides well-structured tables with Users, Accounts, Transactions linked with Foreign Keys.

### 🗂️ Tables
- **users** — Customer information
- **accounts** — Bank accounts
- **transactions** — Money movements

### 🚀 How to Run
1. CREATE DATABASE bankcore;
2. Run schema/schema.sql
3. Run schema/seed.sql
4. Test queries in queries/
